one correlated row UUID and exact original payload per case. Neither display

(default baseline 2.1.296) and checks the actual retained transcript version.

native row/checkpoint handling, target correlation, bounds, uncertainty storage
and no-resend behavior stay unchanged. Unknown 2.1.297/2.1.309/2.2.0 versions
refuse in the existing startup regression. Both qualified versions exercise the
long-label/provenance regression. All 28 module behavior tests pass on host
Node 20.19.0 and Linux Node 22.23.3. No Rust logic, public schema or capability
assessment changes; no new Rust regression result is claimed at this stage.

The next gate is the real generated owned module and consumer callback on
2.1.308. Diagnostic framing is not that integration, native admission, protected
